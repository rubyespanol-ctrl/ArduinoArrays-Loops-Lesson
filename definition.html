Array & For Loops

In the last lesson, you accessed array elements one at a time, by typing each index yourself:

int marks[4] = {70, 85, 90, 65}; Serial.println(marks[0]); Serial.println(marks[1]); Serial.println(marks[2]); Serial.println(marks[3]);

That works, but imagine an array with 100 values — typing 100 print lines isn't practical. A for loop lets you repeat an action automatically, changing the index each time, without writing it out by hand.

The same code, with a for loop

int marks[4] = {70, 85, 90, 65}; for (int i = 0; i < 4; i++) { Serial.println(marks[i]); }

These two pieces of code do the exact same thing — the loop just writes it more efficiently, and works no matter how big the array is.

Why arrays and loops belong together

Arrays store many related values. For loops repeat an action many times. Put them together, and you can visit every element of an array — read it, print it, or change it — using just a few lines of code, whether the array holds 5 values or 5,000.

Key idea: The loop's counter variable (often named i) takes on each index value in turn — 0, then 1, then 2, and so on — which is exactly what you need to visit every slot in an array.
