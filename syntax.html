How Data Works in Array & For Loop

Every for loop follows the same three-part pattern:

for (initialization; condition; increment) { // code that repeats }

initialization — runs once, before the loop starts (usually sets the counter to 0)

condition — checked before every repeat; the loop keeps going while this is true

increment — runs after each repeat, usually increasing the counter by 1

Applied to an array

int marks[4] = {70, 85, 90, 65}; for (int i = 0; i < 4; i++) { Serial.println(marks[i]); }

Here, i starts at 0 and stops as soon as it reaches 4 — which conveniently matches this array's valid indexes: 0, 1, 2, 3.

Tracing it step by step

Here's exactly what happens each time the loop repeats:

Key idea: The loop condition is checked before each repeat. When i becomes 4, the condition i < 4 is false, so the loop stops — it never tries to access marks[4], which doesn't exist.
