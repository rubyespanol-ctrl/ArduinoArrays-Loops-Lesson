Encapsulating an Array + Loop Inside a Class

So far, your array and your loop have lived loosely inside setup(). In Object-Oriented Programming (OOP), you can bundle them together inside a class — a blueprint that packages related data and the actions that work on it into one reusable unit.

Two key words: class & object

class — the blueprint. It defines what data and functions belong together.

object — an actual "thing" built from that blueprint, ready to use in your program.

Private vs. public

Inside a class, you'll usually see two sections:

private: — data only the class itself can use directly. This is where the array usually lives, hidden from the rest of the program.

public: — functions other code is allowed to call. This is how the outside world interacts with the class, without needing to know how it works internally.

Putting it together

class TemperatureLog { private: int readings[5] = {28, 29, 30, 31, 29}; int size = 5; public: void printReadings() { for (int i = 0; i < size; i++) { Serial.println(readings[i]); } } }; void setup() { Serial.begin(9600); TemperatureLog log; log.printReadings(); }

Key idea: The array readings and the loop that processes it are now sealed inside TemperatureLog. Outside code just creates an object (TemperatureLog log;) and calls its public function (log.printReadings();) — it never needs to touch the array directly. That's encapsulation: hiding the details, exposing only what's needed.
