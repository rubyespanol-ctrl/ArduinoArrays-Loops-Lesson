Take Inputs from User and Store Them in an Array

So far, every array you've built already had its values typed in ahead of time. But often you don't know the values yet — you want the user to enter them while the program is running, using the Serial Monitor.

Step 1: Declare an empty array

You can declare an array with just a size, and no starting values. Arduino reserves the space; you fill it in later.

int readings[5]; // empty array, ready to hold 5 values int size = 5;

Step 2: Read input and store it, one at a time

void setup() { Serial.begin(9600); Serial.println("Enter 5 numbers, one at a time:"); for (int i = 0; i < size; i++) { while (Serial.available() == 0) { // wait here until the user sends a number } readings[i] = Serial.parseInt(); Serial.print("Stored: "); Serial.println(readings[i]); } Serial.println("All values stored!"); }

What's new here

Serial.available() — checks whether the user has typed and sent something yet. The small while loop just pauses until input arrives.

Serial.parseInt() — reads whatever number the user typed and converts it into an int your program can use.

readings[i] = Serial.parseInt(); — stores that value into the next empty slot in the array.

Key idea: The for loop still does the same job as before — visiting each index from 0 to size−1 — except now, instead of copying values from { }, it's filling the array with whatever the user types in, one entry per loop repeat.
